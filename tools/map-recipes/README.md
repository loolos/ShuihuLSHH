# 自拼地图配方（§15.15）

每个 `<名字>.json` 是一张地图的配方，`node --experimental-transform-types tools/compose-map.ts [名字]` 生成 `packs/maps/<名字>.json`，预览图在 `extracted/maps/custom-<名字>.png`（加 `--pass` 把不可走的格子涂红）。关卡里用 `"map": { "custom": "<名字>" }`，也可以加 `crop`。改了配方要重跑，`tests/custom-maps.test.ts` 会检查配方和生成的地图一致。

指令说明见 `tools/compose-map.ts` 开头。坐标：x 向右下、y 向左下，(0,0) 在画面最上方。
