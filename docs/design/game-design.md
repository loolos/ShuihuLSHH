# 重制版设计方案（game-design）

> 状态：**第二版**，2026-11-11。这一版按 [原版机制差异审计](original-mechanics-audit.md) 修订：凡有原版证据的地方，默认做法都改成贴近原版。
> 原则（见 [project-overview.md](../project-overview.md)）：**关卡、剧情和整体玩法尽量还原**；具体数值、公式和 AI 在原版未知时才重新设计。
>
> 每条规则都标出依据，等级沿用审计文档：
> - 【A】本仓库的原版数据直接给出（含 EXE 中的界面文字）；
> - 【B】2005 年同期玩家攻略的描述，尚未在本地实机复验；
> - 【C】后来的二手资料；
> - 【新】原版做法未知，由本方案设计；
> - 【待测】需要游玩录像或只读逆向确认。
>
> 需要拍板的事项汇总在 §15。数据见 [data-tables.md](data-tables.md)、[stage-briefs.md](stage-briefs.md)、[script.md](script.md)。

---

## 0. 一页概览

- **类型**：单人、剧情驱动、等距视角的回合制战棋 RPG，浏览器运行，画面随窗口自适应。
- **流程**：主角从护送王進母子开始，一路结识好汉，最终上梁山。关卡表有 76 个槽位、63 张地图：32 关战斗（有胜负条件）、29 个剧情场景、2 个训练场景【A】。其中至少有两处**路线分支**（关西正路 / 山林小径、往沧州的大道 / 小径），由选择决定进入哪一关【A】。
- **主角**：开局输入**姓名和绰号**，默认"武龍""關西之虎"【A】。
- **队伍**：从 2 人逐步扩充到 16 人。多数关卡按原版预置的位置部署；"断后"关要选一名队员与主角一同留下【A】。
- **行动**：每个单位有剩余移动力，可以分段移动；强行军之后不能再行动；攻击会用完剩余移动力；使用道具不耗移动力；可以选"休息"恢复体力和气力【A 菜单项 / B 规则】。
- **成长**：经验满 100 升级，上限 30 级，升级时补满体力和气力；满级后经验满 100 仍会补满【B】。每人按等级习得专属技能，"古武術祕笈"可领悟隐藏技【A】。
- **城镇**：武器店、药铺、当铺、打铁铺、酒店。可以买卖、典当、锻造强化装备，在酒店交谈打听消息【A】。
- **金钱**：击退敌人得到黄金【A】，可典当财宝换钱【A】。
- **重新设计的部分**：伤害、命中和成长的具体公式，技能数值，敌方 AI 细节，UI 布局，现代便利功能。这些地方在原版里没有可靠数据。

## 1. 游戏结构

### 1.1 场景类型【A】

| 类型 | 原版 | 数量 | 特征 | 重制版呈现 |
|---|---|---|---|---|
| 战斗 | `N*`、`N-add*` | 32 | 有回合限制、胜利条件和多条失败条件，每种失败有专门的结局旁白 | 完整战斗 |
| 剧情 | `Act*` | 29 | 没有胜负条件；多为 18×18 的室内小图，以 NPC 为主 | 在地图上演出的过场：单位走位和对白 |
| 训练 | `Train1/2` | 2 | 有地图、单位、对白，"訓練回合數 --- 25" | **原版训练场景**：与王進等对练，能得到经验和道具【B】；是否可跳过【待测】 |

少数 `Act*` 中有 1 个敌方单位（如 Act2-3、Act3-2）。它到底是演出，还是一场简短战斗，【待测】。

### 1.2 流程图：关卡不是一条直线【A】

关卡顺序用 `stageGraph` 表示，节点类型包括剧情、战斗、训练、城镇和选择。已确认的分支：

| 位置 | 选项（EXE 原文） | 进入 | 证据 |
|---|---|---|---|
| 关卡 13（关卡表中的空槽，疑为选择节点） | "此後可走關西正路或山林小徑往延安府，大哥意欲何往？" | 正路 → `N-add04a`（关西大道，官兵拦截）；小径 → `N-add04b`（山贼埋伏） | EXE 字符串；两关章节名同为"第3章 戰役2"，剧本分别是官兵和山贼 |
| 关卡 39–40（空槽） | "大哥，此處前往滄州有兩條路，我們該走哪條？"（小徑 / 大道） | 两条路分别进入 `N-add09a`（官兵、县尉）和 `N-add09b`（山贼），具体对应【待测】 | 同上；两关章节名同为"第8章 戰役1" |

另外三组带 `a` 后缀的剧情场景（`Act5-1a`、`Act7-1a`、`Act11-1a`）可能是分支后的不同过场【待测】。关卡表里 13 个空槽，可能是城镇或其它非地图节点【待测】。

### 1.3 核心循环

```
剧情（Act）→ 战前对白 → 战斗（N）→ 胜利旁白 → 城镇 / 整备 → 选择路线 → 下一段剧情
                  ↑ 失败：播放对应结局旁白 → 读档
```

- **城镇**【A 店铺种类 / 新 呈现方式】：武器店、药铺、当铺、打铁铺、酒店。店铺菜单为"離開 / 打鐵 / 典當 / 物品 / 交談"，店员台词如"客倌，抓藥嗎？""有寶刀需要鍛造嗎？"。酒店里能听到关于前方地点的消息（如"前方有個史家莊…"）。城镇在流程中出现的位置【待测】。重制版先做成菜单式城镇（§15 D-11）。
- **失败**【A】：播放该失败条件对应的结局旁白（如 N01 的"王母在混戰之中被官兵所殺…"），然后回到读档。另提供"从本回合重来"【新】。
- **存档**【A】：原版有"存檔 / 載入 / 取回進度"和多个进度槽。重制版另外在关卡开始时自动存档【新】。

### 1.4 队伍、出场与延迟加入

- **默认部署**【A】：按每关 ACT 中的单位和坐标部署。不能从"ACT 里有几个人"推出"原版从不选人"。
- **断后选人**【A】：N-add15 中，"留下一個人與我阻擋追兵，其餘的人先走…"，接着"請選擇留下的人"。也就是主角加一名玩家选的队员留下作战，失败旁白是"斷後失敗…"。重制版用 `chooseUnits` 事件实现，选人界面、人数上限和战后如何归队【待测】。
- **延迟出场**【B，A 旁证】：攻略说 N01 中武龍第 3 回合才加入。N01 的 ACT 里，武龍的 w7 = 1，而开局即在场的王進 w7 = 0。全部关卡里 w7 最低位为 1 的单位有 366 个，敌方占 265 个，很可能就是"由事件激活的增援或延迟出场"【低，待测】。重制版：w7 最低位为 1 的单位初始隐藏，由事件 `activate` 出场。
- **等级**【A 数据 / 低 解释】：好汉在 ACT 中多写 Lv1，推测表示"沿用存档等级"。新加入者写着明确等级（林沖 10、魯智深 7、楊志 18…）。N-add14 中只有部分好汉有明确等级（武龍 30、晁蓋 23、劉唐 21、公孫勝 23、阮氏三人 22–23、吳用 20、白勝 20），其余仍是 Lv1，语义【待测】。

## 2. 战场

### 2.1 地图与坐标【A】

- 菱形等距格，每格画面 90×46；地图为 18×18、36×36、54×54，以及一张 36×54。
- 格子 (x, y) 的屏幕中心 = ((x − y) × 45, (x + y) × 23)。已用 63 张图验证，接缝连续【中】。
- 每格 1 层地表，加 0–4 层地上物。先画地表，再按 x + y 从远到近画地上物和单位；单位被遮挡时半透明显示【新】。
- 原版有"查看地圖"命令。

### 2.2 通行与阻挡

- **图块通行**【A 数据 / 低 语义】：`Ground.att` / `Upper.att` 标记 0 或 0xFF，推测 0xFF = 不可通行。配合人工修正表 `overrides/passability.json`。
- **单位阻挡**【B】：任何有单位的格子都不能穿越，包括友方；敌人会绕开堵路的单位。是否有换位或穿越技能【待测】。
- **地形效果**：原版没有找到地形表，第一版只分"可走 / 不可走"【新】。
- **区域控制（ZOC）**：不做【新】。

### 2.3 朝向【A 存在 / 用途待测】

单位有 4 个朝向（ACT 字段 0–3，`Man.lib` 每个动作 4 方向）。**默认只用于表现**：朝向最后的移动或攻击方向。背后攻击加成没有原版证据，只作为可选的重制规则，默认关闭（§15 D-3）。

### 2.4 回合与行动

**回合**：原版有"回合終了"和"當前回合數"【A】。阵营先后顺序【待测】，暂定我方全体 → 友军 → 敌方【新】。系统选项"敵方行動"推测用于切换是否显示敌方行动过程【低】。

**单位的行动菜单**【A】：

| 菜单 | 原版字样 | 说明 |
|---|---|---|
| 移动 | 移動 | 见下方的移动规则 |
| 普通攻击 | 普通攻擊 | 用完剩余移动力【B】 |
| 特殊攻击 | 特殊攻擊 | 使用技能，消耗气力 |
| 防御 | 防御 | 本回合进入防御状态，效果【待测】，暂定受到伤害 −50%【新】 |
| 使用 | 使用 | 使用道具，**不消耗移动力**【B】；一回合内能否连续使用【待测】 |
| 装备 | 裝備 | 战斗中可以换装备【A 菜单 / 待测 是否消耗行动】 |
| 给予 | 給予 | 把物品交给相邻队友【A 菜单 / 新 规则：只限相邻】 |
| 丢弃 | 丟棄 | 丢弃物品 |
| 休息 | 休息 | 结束行动并恢复体力和气力【A】；有资料说各恢复最大值的 1/15【C】，比例和取整【待测】 |
| 人物资料 | 人物資料 | 查看属性 |

**移动规则**【B】：

- 绿色范围：在剩余移动力内移动，可以分段，移动后仍能行动。
- 黄色范围：强行军，走得比绿色更远，到达后本回合结束。黄色范围的计算方式【待测】，暂定绿色范围再加 50%【新】。
- 状态机字段：`movementRemaining`、`forcedMarch`、`attackUsed`、`actionEnded`。不能只用一个"已移动"标记。

**新增便利功能**【新】：撤销最近一次移动；"全体待机"；敌方回合快进。

## 4. 战斗计算

原版的公式不知道，下面是【新】公式，但手感参数尽量贴近原版描述。行动前显示命中率和伤害范围。

### 4.1 伤害与命中【新，参数可调】

```
命中率   = clamp(70 + (攻方命中 − 守方敏捷) × 0.5, 10, 99) %
A        = 攻方攻击 + 武器攻击加成
D        = 守方防御 + 衣服防御加成 + 头饰防御加成（防御状态时 D × 2）
基础伤害 = A² / (A + D) × 0.5
普通攻击 = 基础伤害 × 随机系数
技能伤害 = 基础伤害 × 技能威力系数 × (1 + 攻方必杀 / 255) × 随机系数
暴击     = 概率 clamp(攻方必杀 × 0.4, 0, 50) %，伤害 ×1.5
```

- **随机幅度**【B】：攻略记录原版伤害波动非常大，有时只有正常值的约十分之一。默认采用"原版手感"预设：随机系数在 0.1–1.3 之间，以 1.0 为中心偏态分布（多数结果落在 0.8–1.2，偶尔出现极低值）。另有"稳定"预设 0.9–1.1（§15 D-9）。
- **必杀的作用**【B】：攻略说必杀指数影响必杀技的实际伤害，所以必杀同时作用于暴击率和技能伤害。
- **比例式 `A²/(A+D)`**：防御高时伤害递减但不归零。原版装备加成从 +6 到 +50 跨度很大，减法公式容易"破不了防"。
- 以 N01 为例：武龍（攻 72）打士兵（防 20，生命 50）约 28 点；士兵（攻 50）打武龍（防 37）约 14 点。
- 装备加成取自道具说明中的"攻擊力加N / 防御力加N"（78 件武器、56 件防具）【A】。
- 战斗消息照原版字样【A】："MISS""未造成敵方傷害。""N 點傷害。"，范围技能显示"造成敵方總共 N 點傷害"。

### 4.2 远程与反击

- **远程**【A 类别】：弓箭手的普通攻击是"遠程攻擊"，射程暂定 2–3 格【新】。
- **反击**【A 存在 / 待测 规则】：EXE 中有战斗消息"施展反擊技，"，说明原版的反击是**技能**，不是所有单位都会的通用规则。重制版只让带反击技的单位反击。哪些技能属于反击技、触发条件和概率【待测】，第一版先给"防禦技"类技能加反击（§15 D-2）。

### 4.3 状态异常【A 种类和消息 / 新 数值】

| 状态 | 原版消息 | 效果 | 解除 |
|---|---|---|---|
| 中毒 | "中毒了！""毒發，生命力損失 N 點。" | 每回合开始扣最大生命的 10%（暂定） | 解毒草藥、天山雪蓮；"狀態恢復正常了！" |
| 昏迷 | "昏迷了！" | 跳过下一次行动（暂定） | 解昏迷草藥、天山雪蓮 |
| 增益 | — | 按道具说明，如"3 回合內攻擊力提升5點" | 到期 |

## 5. 成长

### 5.1 经验与升级

- 满 100 经验升 1 级，上限 30 级【A，Editor 分析】。
- **升级补满体力和气力**；**满级后经验每满 100 仍补满一次**，经验条循环使用【B】。
- 获得经验的规则【B 定性 / 新 数值】：攻击命中、击倒、治疗都给经验；治疗按回复的体力给经验；**只回复气力不给经验**。暂定数值：命中 10、击倒 30、治疗 = 回复量 ÷ 10（上限 20），乘以等级差系数 `clamp(1 + (敌等级 − 己等级) × 0.1, 0.3, 2.0)`。
- 原版消息【A】："升級了！""得到了 …""領悟了 …"（学会技能）。

### 5.2 属性成长【A 字母 / 新 数值】

原版每项属性带一个等级字母（f、g、h、i、j、n）。防御和敏捷几乎全是 n；王進的生命是 f，而他的初始生命最高。推测字母越靠前成长越高：

| 字母 | 生命/气力 每级 | 攻/防/命/敏/必 每级 |
|---|---|---|
| f | +12 | +4 |
| g | +10 | +3.5 |
| h | +8 | +3 |
| i | +7 | +2.5 |
| j | +6 | +2 |
| n | +4 | +1.5 |

这张表需要用升级前后的属性截图校准。

### 5.3 永久提升【A】

- 兵书：鬼谷子兵法 攻 +10、孫臏兵法 防 +10、孫子兵法 命 +10、黃石公兵法 敏 +10、孔明兵法 四项各 +5。
- 古武術祕笈：领悟下一段隐藏技（LV1 → LV2 → LV3），需要达到学习等级；条件不满足时显示"無法領悟"【A】。

## 6. 技能

### 6.1 结构【A】

- 好汉各有 4–13 个专属技能（宋江没有），按等级 1–30 习得。
- 分级技能（千軍萬馬 LV1–3、天王托塔 LV1–5）：高级取代低级。
- 每人 3 段隐藏技，需要古武術祕笈。
- 8 个类型标签：普通攻擊、遠程攻擊、防禦技、連續技、迴旋技、氣功技、集氣技、回復技。NPC 职业直接以这些类型名作为技能（如都頭：普通攻擊、迴旋技、集氣技）。

### 6.2 命中范围：离散格子形状【B】

同期攻略把技能范围分为**点、圈、线、面**，并细分为贴身/远程、4 面/12 方、三角、菱形、方圆等。重制版的每个技能都存 `targetShape`：

| 字段 | 含义 |
|---|---|
| `castRange` | 施放距离：0 = 以自身为中心，1 = 贴身，2+ = 远程 |
| `shape` | `point` / `ring4`（四面）/ `ring12`（十二方）/ `line` / `triangle` / `diamond` / `square` / `custom` |
| `size` | 形状大小 |
| `offsets` | `custom` 时逐格列出相对偏移；每个等级可以不同 |
| `directional` | 是否随施放方向旋转（线、三角） |

每个技能的具体形状，以攻略中的分类表为初稿，再用录像核对。

### 6.3 数值基线【A 字段 / 低 解释】

技能子项中有几个字段的规律像"气力消耗 / 范围 / 威力"：

| 字段 | 千軍萬馬 LV1 / 2 / 3 | 五雷咒 LV1 / 2 / 3 | 推测 |
|---|---|---|---|
| +8 | 25 / 45 / 60 | 40 / 50 / 70 | 气力消耗 |
| +16 | 3 / 5 / 7 | 2 / 3 / 4 | 范围大小 |
| +18 | 60 / 100 / 200 | 80 / 150 / 250 | 威力 |

基础招式的 +8 为 0，符合"普通攻击不耗气"。重制版直接用这三个字段作初值。

### 6.4 特效

`Effect.lib` 有 60 组特效，与技能的对应未知，先手工指定。

## 7. 装备、道具、城镇与经济

### 7.1 装备栏与物品管理【A】

- **典当**：卖出道具和财宝。

## 8. 敌方与友军 AI

原版 ACT 的 w7 字段很可能编码了行为：最低位疑为"延迟出场"（§1.4），高字节 0–8 疑为行为模式【低】。EXE 中还有埋伏用的台词："不行...還不夠近，再等等....""好！大家上！""王教頭！我們要不要衝出去？"【A】，说明原版有"等玩家靠近再出击"的伏兵行为。

重制版行为模式【新，默认值按 w7 推测，再人工修正】：

| 模式 | 行为 | 原版线索 |
|---|---|---|
| 冲锋 | 朝最近的可攻击目标移动并攻击 | — |
| 埋伏 | 我方进入一定距离后出击，并播放出击台词 | EXE 埋伏台词；N01 中 w7=512 的一组 |
| 固守 | 不移动，目标进入攻击范围才攻击 | — |
| 追击目标 | 优先攻击指定单位（如官兵追王母） | N01 失败条件 |
| 护卫 / 跟随 | 跟随指定单位（如王母跟随王進） | 审计 P0 |
| 撤退 | 朝撤退区域移动 | N01 胜利条件 |

敌人会绕开被占据的格子【B】。目标选择：能击倒 > 伤害最高 > 生命最低 > 最近【新】。

## 9. 剧情与事件

### 9.1 内容还原【A】

- 853 句对白，以及全部旁白、目标、结局文字，按原文使用。
- 开局输入"姓名"和"綽號"（"請輸入主角姓名及綽號："），默认武龍 / 關西之虎。`%X`、`%N` 替换为主角名；绰号如何代入文本【待测】。
- 头像：`Head.lib` 79 张，与角色的对应需要人工标注。

### 9.2 事件脚本【新格式，内容以原版为准】

PAS 的事件指令还没有解开，所以每关的事件由人工编写，以剧本文本、EXE 字符串和游玩录像为准：

```jsonc
// content/stages/N01.events.json（示意）
{
  "objective": {
    "turnLimit": 50,
    "win":  [{ "reach": { "unit": "王母", "area": "escape" } }],
    "lose": [{ "dies": "王進", "ending": "lose_wangjin" }, { "dies": "王母", "ending": "lose_mother" },
             { "dies": "$hero", "ending": "lose_hero" }, { "turnLimit": true, "ending": "lose_timeout" }]
  },
  "areas": { "escape": "待测：撤退区域位置" },
  "events": [
    { "on": "start", "do": [{ "say": "王進", "line": "pab:N01#0" }, "…"] },
    { "on": { "turn": 3, "phase": "player" }, "do": [{ "activate": "hero" }, { "say": "都頭", "line": "pab:N01#…" }] },
    { "on": { "near": { "group": 512, "distance": "待测" } }, "do": [{ "ai": { "group": 512, "mode": "冲锋" } }] }
  ]
}
```

需要支持的能力：

- **触发**：回合开始、单位进入区域或靠近、单位倒下、生命低于某值、对话结束。
- **动作**：对白、激活或增援（"敵軍增援了！"）、移动、改 AI、加入队伍、给道具、**中途改变胜负条件**（N-add09a 先是"打敗所有敵人"，后改为"打敗縣尉"）、结局。
- **选择**：`chooseRoute`（路线分支）、`chooseUnits`（断后选人）。
- 对白通过 `pab:关卡#序号` 引用原文，文本不复制进事件文件。

### 9.3 编写顺序

先写第 1–3 章（关卡 0–16，含第一个路线分支）作为竖切片。每章需要一段游玩录像，用来核对出场时机、撤退区域和分支。

## 12. 技术架构

### 12.1 模块划分

```
src/
  formats/     原版格式解析（已有），浏览器与 Node 共用
  data/        整理成游戏数据：Character、ClassDef、Item、Skill、StageDef、StageGraph
  rules/       纯 TypeScript 规则引擎：棋盘、寻路、行动状态机、战斗计算、AI、事件执行
  game/        Phaser 4 场景与表现层：Boot、Setup、Title、Naming、Story、Battle、Town、Camp、Settings
  content/     手写内容：事件脚本、stageGraph、通行修正、技能形状、AI 指定、头像对照、平衡参数
tools/         Node 工具（已有：gen-design-docs、render-maps）
```

### 12.2 关键设计

- **自带原版文件**：首次启动时选择原版目录，在 Web Worker 中解码，结果缓存在 IndexedDB。
- **规则与表现分离**：`rules/` 输出事件流，`game/` 只负责播放；方便快进、自动测试和数值模拟。
- **规则开关**：每条【新】规则（背后加成、地形、稳定随机等）都可以在配置里开关，默认值按 §15 的决定。
- **证据标注进配置**：规则配置里记录 `originalEvidence`、`remakeDecision`、`pendingValidation`，与本文档同步。
- **存档**：JSON 存在 IndexedDB，可导出、导入。
