## 2. 属性与成长（0x408540，高）

```
属性(等级L) = 基础值 × (g / 100)^L        g = HUM 中的"成长字母"字节
```

- 之前文档里的成长等级字母 f/g/h/i/j/n，其实就是字节值 102/103/104/105/106/110，也就是**每升一级乘以 1.02–1.10**。
- 计算时先封顶 510，再截断取整。
- 然后：
  - 加上装备加成；
  - 生命和气力封顶 510，攻防命敏封顶 255；
  - 中毒时攻击和防御减半。
- 我方单位等级上限 30；敌方没有这个限制。
- **升级会完全回复生命和气力**（0x406990）。
- 升级时会提示"領悟了"新技能：技能子项 +17 是习得等级。

## 3. 一次攻击的结算（0x406c60，高）

### 3.1 命中

```
命中率 = 攻方命中 − 守方敏捷 / 2 + 技能命中修正(+20)
  若小于 0，按 0 计
  × 朝向系数：攻守朝向相同（打背后）×1.5；侧面 ×1.3；正面 ×1.0
  × 0.7（守方处于"防御"状态时）
  ≥ 100 时必中；否则取保底：攻方是我方时最低 80%，敌方或友军时最低 30%
随机 rand()%100 < 命中率 → 命中
```

- "朝向系数"中"相同 = 背后"是根据 4 方向编码推出的（中）。
- 原版**有背后攻击加成，但只作用于命中，不作用于伤害**。
- 我方命中**保底 80%**，这是原版手感的一个关键。

### 3.2 防御状态下的反击（0x407720，高）

- 攻击被闪避时，如果同时满足下面三条，守方会立即用普通攻击反击：
  - 守方处于"防御"状态；
  - 双方正交相邻（0x41e410：同行或同列，距离 1）；
  - 50% 的几率判定成功。
- 这次反击**必定命中**（+0x20 标志 0x1000 会跳过命中判定），战报显示"施展反擊技，"。
- 所以原版的"反擊技"**不是某个技能，而是防御指令的效果**。这推翻了 PR #5 的推测（§15 D-2）。

### 3.3 中毒、昏迷（命中后判定）

- 中毒率 = 技能 +10 + 攻方装备的中毒率；判定成功则中毒 2–4 回合。
- 昏迷率 = 技能 +11 + 攻方装备的昏迷率；判定成功则昏迷 2–4 回合。
- 中毒效果：
  - 攻击和防御减半；
  - 每回合开始时失去最大生命的 1/20（0x40525b，"毒發，生命力損失 N 點。"）。

### 3.4 必杀与伤害

```
必杀率 = (攻方必殺 + 技能必杀修正(+22)) / 2
必杀： 伤害 = 2 × (攻方攻擊 + 技能威力(+8)) − 守方防禦
普通： 伤害 = 攻方攻擊 + 技能威力 − 守方防禦
若伤害 ≤ 0：伤害 = 10 + rand()%50（10–59 的随机值）
伤害 × 本段比例 / 100（多段技能每段有自己的比例）
× 0.7（守方防御状态）
实际扣血不超过 当前生命 − 生命下限(+0x3e)
```

- 普通攻击的伤害**没有随机浮动**，随机性只来自命中、必杀和"破防保底"。
- 我们定的 ±10% 浮动（D-9）属于新设计。

### 3.5 回复技与集气技（0x406bd0，高）

- 回复技（类型 9/11）：回复量 = 目标最大生命 / 技能 +8。例如 +8 = 3 时回复 1/3。
- 集气技（类型 8）：回复量 = 目标最大气力 / 技能 +8。

### 3.6 经验与金钱（高）

只有我方（阵营 0）获得经验。每满 100 升一级，溢出的部分保留。

| 事件 | 经验 |
|---|---|
| 击倒敌人 | max(1, 敌等级 − 我等级) × 12 + 1–9 |
| 命中但未击倒 | 伤害 / 10 + 1–2 |
| 使用回复技 | 1–10 |

- 击倒敌人得到的黄金 = 1 + rand()%(HUM +29)。例如：士兵 50、都頭 200、高俅 500；好汉职业为 0。

### 5.2 打铁（0x418290，高）

- 每次提升收费为**买价的一半**。
- 一次提升会同时加攻击和防御（只加还有剩余次数的那一项），并各减 1 次剩余次数。
- 例：青絲手套攻击 9，每次 +2，可提升 4 次。
- 只能在 +172 列出的城镇提升；钱不够时提示"金錢不夠，無法提升！"。
- 城镇号的出现顺序是 1,2,3,4,5,13,6,12,7…，与 PAS 头部 +9 的城镇号（只有 13 个文件非 0）吻合，推测是剧情中经过城镇的顺序（中）。

## 7. PAS 剧本脚本结构（高 / 中）

### 7.1 文件头与区块

- 文件头：`"PAS"`，然后：
  - u32 正文长度；
  - u16 区块数（+7）；
  - u16（+9）城镇号 1–13，只有 13 个文件非 0；
  - u32（+11）用途未知。
- 每个区块的结构：
  - u16 长度；
  - 9 个 u16 头字：w0 = 1 为普通区块，4/5 为区域触发；w8 是触发类型。
- 63 个文件中，区块长度之和都恰好等于文件长度。

### 7.2 触发类型（w8）

| 类型 | 触发条件 | 参数 |
|---|---|---|
| 0 | 第 N 回合 | 0 = 开战时；N01 的第 2 个区块在回合 2 触发，即武龍在第 3 回合登场 |
| 1 | 某单位死亡 | 角色号，1000 = 主角 |
| 4 | 某单位进入区域 | 带可变长条件，编码未解。N01：王母进入撤退区 |

- 类型 0/1 的区块在头字后接 `ffffffff` 和一个 u16 参数，指令从区块偏移 26 开始。

### 7.3 指令

- 指令格式：u16 长度、u16 操作码；操作码 < 24 时再跟一个 u16 标志；最后是指定长度的载荷。
- 全部 285 个类型 1 区块都能按这条规则完整切分。

| 操作码 | 含义 | 置信度 |

| 12 | 选定人物（标志 1 = 角色号；标志 0 = 1000 + ACT 单位序号） | 中 |
| 13 | 说话 | 高 |

## 8. 对设计方案的影响

| 设计条目 | 原版实际 | 建议 |
|---|---|---|
| D-2 反击只给"反擊技"技能 | 反击是**防御指令**的效果：防御中闪避相邻攻击时，有 50% 几率普通攻击反击，必中 | 已确认按原版 |
| D-3 背后攻击加成默认关闭 | 原版有：命中 ×1.5（背）/ ×1.3（侧），不加伤害 | 已确认按原版 |
