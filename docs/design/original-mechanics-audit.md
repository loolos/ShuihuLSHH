# 原版机制差异审计（2026-11-11）

> 目的：对照 `game-design.md` 的重制设计与可核实的原版行为，明确哪些属于**原版已知玩法**、哪些是**刻意的新设计**、哪些还需**实机验证**。这是一份**设计审查**，不是原版公式的反编译证明；不会擅自把攻略经验当成源码事实。
>
> 证据分级：**A** = 本仓库原始数据直接反映；**B** = 2005 年同期实际玩家攻略明确描述（未做本地实机复验）；**C** = 后来攻略/视频佐证；**U** = 尚未确认。
>
> 核心同期来源：[mf48，轩辕春秋《水浒传之梁山好汉》攻略（2005）](https://www.xycq.org.cn/forum/thread-60415-1-1.html)，文中第一帖讨论操作、经验、物品、AI；第二帖逐关描述剧情。后续佐证：[侠外论坛攻略转述](https://bbs.xiawai.com/thread249717p1v1)、[游戏121攻略](https://www.youxi121.com/shouji/229.html)。外部转载可能互相转引，**不能把它们当作独立复验**。

## P0：建引擎前必须修改/验证

| 主题 | 目前 GDD | 原版证据与结论 | 处理 |
|---|---|---|---|
| 行动力 | §2.4「移动一次 + 一个行动，移动后还能行动」 | **B**：绿色范围可多次分段移动直到机动力耗尽；黄色范围为强行军，到达后不能再行动。普通攻击耗尽机动力。 | 改为剩余移动力驱动的行动状态机，不用单一 `hasMoved`。先保证基本绿/黄两种移动。黄色边界的精确计算需实测。 |
| 物品与休息 | §2.4 把道具与攻击当作互斥行动；未定义休息效果 | **B**：使用物品不消耗机动力，玩家可先补给再移动/攻击。休息会恢复 HP 和 MP；「各 1/15」仅见后续整理，具体舍入与上限未知。 | 道具不与攻击简单互斥；实现行动前后的可用状态。休息列为动作，具体回复系数单列 `pendingValidation`。 |
| 单位阻挡 | §2.2「可穿过友方」 | **B**：攻略明确描述不能从有人占据的格子通过，敌人会为堵路绕行。 | 阻挡所有被占据的格子；是否允许交换、斜角裁切需实测。 |
| N01 武龙事件 | §9.2 示例在「第1回合」`spawn: hero` | **B**：原版攻略明确为第 **3 回合**加入；**A**：`N01.act` 中已包含武龙单位记录，记录≠开局可见。 | 把事件样例改为 `turn: 3` 的候选触发，并要求与 `w7`/PAS 或实机对照；避免从 ACT 初始记录推断即刻出场。 |
| 全员出场/队伍选择 | §1.3、D-1 认定「原版每关全员出场，无选择」 | **A**：本仓库 `stage-briefs.md` 的 N-add10 只有 1 个我方记录，N12 15 个我方+晁盖友军，不能以「每个战场预置数」证明「全队总在场」。**B/C**：原版逐关攻略中「断后」要求选两名队员留下；「弃庄」「逃亡」有官道/小路路线选择。 | **默认沿用 ACT 固定部署**，但必须支持 `chooseUnits`（指定人数）与 `chooseRoute` 事件，不必把所有关都开放自由部署。先定位对应关卡/PAS 分支。 |
| 训练关性质 | §1.1 写为「可选的练习战」 | **A**：Train1/2 有地图、单位、对白、25 回合设置；**B**：玩家描述在延安府与王进练功、可获得经验/秘笈。是否可跳过尚无证据。 | 改为「原版训练场景；是否可选待核」，保留奖励/成长与重复战斗逻辑，不默认只做无影响的练习。 |

## P1：数值和系统的遗漏/差异

| 主题 | 已知信息 | 设计建议 |
|---|---|---|
| 30级后的经验循环 | **B**：升级 HP/MP 补满；到 30 级后经验每满 100 仍能恢复 HP/MP。攻略还记载治疗 HP 按目标得经验、单纯恢复 MP 不得经验（经验点数有波动）。 | §5.1 不要用「升到30后 XP 全部停用」；可把满级经验条做成循环回复资源。经验系数仍是新设计，需在 UI 中说明。 |
| 必杀属性的用途 | **B**：玩家报告「必杀」指数会影响必杀技实际伤害；它不只是普通攻击的暴击概率。 | §4.1 可继续采用新伤害公式，但 **不要把原版的「必杀」只当暴击率**；考虑分别影响暴击和技能伤害，或注明纯重制改动。 |
| 伤害随机幅度 | **B**：攻略记录攻击/必杀伤害波动非常大，有时约为正常的十分之一；§4.1 仅 `0.9–1.1` 属明显收窄波动。 | 收窄随机可作为现代化取舍，但应明确标记；用原版手感模式/可选随机性预设，而非冒充原版。 |
| 技能范围几何 | **B**：同期攻略把技能归成「点、圈、线、面」，并细分贴身/远程、4面/12方、三角/菱形/方圆，列出武龙等人的对应招式。 | §6.2 的「半径1–3菱形」不能覆盖全部类型。独立实现 `targetShape`（点、直线、环绕、三角、菱形、方形等），必要时存每级离散格偏移。 |
| 商店和锻造 | **B**：攻略提及在城镇买卖、铁匠铺锻造、武器提升。 | §1.2「商店位置未知」、§7.3「强化完全自设」需区分：**商店与锻造确实存在**，但价格/成长/成功率及开放条件未知；+10%/上限5作为重制建议保留，不当作还原。 |
| 主角称号与命名 | **C**：[中文百科二手介绍](https://www.newton.com.tw/wiki/%E6%B0%B4%E6%BB%B8%E5%82%B3%E4%B9%8B%E6%A2%81%E5%B1%B1%E5%A5%BD%E6%BC%A2/10937614) 记载姓名「武龙」及绰号「关西之虎」均可改；**A**：EXE 有绰号表，脚本有 `%X` / `%N` 占位。 | D-5 应支持 `hero.name` 和 `hero.nickname` 两个字段，但原版具体输入与替换规则待验证。 |
| 阵营回合与先后顺序 | **U**：无法由 ACT/PAS 的回合限制文案推出「我方全体→友军→敌方」和「按敏捷排序」。 | 暂按重制规则实现，但在文档标记为新设计；不把敌方敏捷排序写成原版。 |
| 朝向伤害、反击、掩体 | **U**：ACT 有朝向字段不等于原版存在背刺加成；未找到反击和掩体的可靠原版说明。 | 都保持为**可关闭的新设计**，不作为最初还原版的强制规则；建议先按当前草案做好开关。 |
| 章节数和流程分支 | **A**：关卡表有 76 个槽位、63 个实际地图，尾项 `N14` 的 EXE 章节名是「第15章 战役1」。**B**：至少「弃庄」和「逃亡」存在路线分支。 | 不把「14章」和「63关顺序全串行」写成已证实；用 `stageGraph` 和选择节点，待定位 EXE/PAS 实际进入条件。 |
| N-add14 固定等级 | **A**：部分有明确等级，很多队友在 ACT 中是 Lv1；§1.3 说「16名好汉都有明确等级、这是固定配置关」与 stage-briefs 不符。 | 将 `Lv1` 是否表示从存档读取列为假设，不直接固定全员等级；可以根据入场时机单独覆盖。 |

## P2：用户期望的高清重制与当前画面方案

- §10.1 的「最近邻整数放大原版像素」实际上是**原版画风模式**，尚不是高清重制。建议拆成两个可切换资源管线：`classic`（原图整数放大）、`remastered`（重新绘制地形、角色图集、UI），共享同一格坐标、碰撞和事件数据。
- 第一阶段不要强行做全套 HD 素材：先用原图本地解码验证 `N01`，随后选择 1 地图、3 角色、1 套 UI 做 HD 垂直切片，以证明资源比例、透视和遮挡可行。
- GitHub Pages 的「选择玩家本地原版目录」技术方案与自动运行的公开 Demo 是两件事。无原版资源的访客应该得到清晰的引导/合法原创 demo 素材，不能默认页面打开就有可玩的游戏。
- 现有仓库是私有、包含 `gamedata/shuihu` 原始数据。**先保持私有**；公开前对 Git 历史、发布构建、Actions 日志、资产清单做检查。仅 `.gitignore` 无法移除已经提交过的原版资产。

## 推荐落实顺序与测试

1. **先改 §2.4 行动状态机**：测试分段绿色移动；强行军后不能攻击；道具不会消耗移动力；攻击后无剩余移动；有人占据的格不能穿越；休息回复。
2. **再改 §9.2 第一关事件**：测试武龙在第3回合（或 PAS 明确触发时）加入；王母跟随王进；进入撤退区胜利，任一保护目标死亡失败。
3. **再处理关卡路由**：测试官道/小路选择进入对应关卡；断后选择两名队员，正确恢复全队；训练场景有经验和道具收益。
4. **P1 数值与技能形状**：把每一条差异记录成 `originalEvidence`、`remakeDecision`、`pendingValidation`，不要阻塞第一关。
5. **静态逆向与游玩证据双轨**：关键规则拍 10–30 秒录像或在只读 EXE 中找对应函数，再将“B/C”升级为本地可验证证据。

## 需要用户实测的短清单

- 绿色/黄色范围的距离边界、道具之后能否连续使用、何时结束角色行动。
- 休息回复比例与取整；等级30经验满100后的实际恢复过程。
- 原版有无反击与背后攻击加成、技能各形状的精确格子范围。
- 「断后」选择两人的界面、替换队员后战斗地图和主线恢复规则。
- N01 第3回合武龙出现的脚本触发时点与准确出生位置。
