## 0. 目标与约束

### 0.1 目标

- **做什么**：用 **Phaser 4 + TypeScript** 在浏览器中重制原作，做成单人、剧情驱动、等距视角的回合制战棋 RPG。
- **还原范围**：关卡、地图、单位配置、剧情、人物、道具、技能体系、规则和数值都按原版。
- **现代化**：UI、操作、便利功能、音乐、存档是新做的。

### 0.2 已定方针（负责人，2026-11-11）

| 项目 | 决定 |

## 1. 游戏结构

### 1.1 场景类型

| 类型 | 原版文件 | 数量 | 特征 | 呈现 |
|---|---|---|---|---|
| 战斗 | `N*`、`N-add*` | 32 | 有回合限制、胜利条件和多条失败条件，每种失败有专门的结局旁白 | 完整战斗 |
| 剧情 | `Act*` | 29 | 没有胜负条件，多为 18×18 室内小图 | 地图上的过场：走位加对白 |
| 训练 | `Train1/2` | 2 | 与王進等对练，25 回合 | 正常战斗，能得到经验和道具；能否跳过【待核】 |

- 关卡表有 76 个槽位：63 张地图，加 13 个空槽。空槽不是城镇：每关 `.pab` 文件头 +11 记着下一关，全部跳过空槽；城镇号在文件头 +9（见 §7.5）。
- Act2-3、Act3-2 里各有 1 个敌人。它们是演出还是短战斗【待核】。

### 1.2 流程图

关卡顺序用 `stageGraph` 表示。节点类型：剧情、战斗、训练、城镇、选择。

路线分支（EXE 0x418c60 / 0x4138b9，见 binary-formats §8「分路」）：

| 何时问 | 问题 | 大道 | 小径 |
|---|---|---|---|
| 离开城镇 2（Act3-4 之后） | "此後可走關西正路或山林小徑往延安府，大哥意欲何往？" | `N-add04a`（官兵拦截） | `N-add04b`（山贼埋伏） |
| 离开城镇 5（N07 之后） | "大哥，此處前往滄州有兩條路，我們該走哪條？" | `N-add09a`（官兵、县尉） | `N-add09b`（山贼） |

两条路打完都接同一关（`Act5-1a` / `Act8-1`）。`Act5-1a`、`Act7-1a`、`Act11-1a` 不是分支专属，而是正常顺序里的过场。

**已实现（关卡串联）**：下一关读剧本头 +0x0B（`nextByHeader`，`src/rules/campaign.ts`）。城镇 2、5 那两关结束后先弹原版对话框：问题、「大道 / 小径」两个按钮，选后主角说对应台词；选小径进 b 关。城镇界面做好之前，对话框放在那一关结算之后（Act3-4 是过场，演完直接问）【新】。Act 剧情关演完自动接下一关，战役打完显示"继续"。

### 1.3 核心循环

```
剧情 → 战前对白 → 战斗 → 胜利旁白 → 城镇 / 整备 → 选择路线 → 下一段剧情
             ↑ 失败：播放对应的结局旁白 → 读档或从本回合重来【新】
```

- **存档**：原版有多个进度槽。另外在每关开始时自动存档【新】。
- **已实现**：进入下一关时把进度（下一关、我方人物的等级/经验/装备、累计黄金）自动存到浏览器 localStorage，重开页面从这一关继续；关卡下拉框可以跳关（人物按那一关重新配，见下条），选"新游戏"清空。每关开始体力、气力回满【待核】。
- **测试用跳关【新】**：用左上角下拉框（或网址 `?stage=`）直接进后面的关卡时，我方人物按那一关重新配等级和装备，免得拿 1 级人物打后期：之前的等级、经验、装备一概不沿用（只保留黄金），所以来回跳关时同一关的人物等级总是一样；等级 = 该关敌人的平均等级（不低于剧本里写的等级），武器、衣服、头饰在剧本初始装备的基础上换成之前最后一个城镇武器店里本职业能用的最好的一件（比初始的好才换），物品栏补 2 个药铺里回复最多的药；技能随等级领悟（`src/rules/preset.ts`）。原版没有这个功能。下拉框里每个过关后进城的关卡下面还有一项「城镇 地名」（网址 `?stage=town:<关卡名>`），直接进那个城镇：等级按城镇之后的下一关配，装备只用这个城镇之前的店（这个城镇的货留给玩家自己买），黄金 = 打到这一关为止每个敌人掉钱的期望值（(上限+1)/2）之和，手上钱更多就保留；分路的两关只算走的那一条（`jumpToTown`）。
- **关卡名字【新】**：下拉框按章分组，组名「第N章 章名」，组内「战役一 关名」「训练 关名」「剧情 关名」「城镇 地名」；城镇页标题也用地名。章名多借原著回目，关名按各关剧本内容起，都是 3–6 字（`src/game/stage-names.ts`）。章号、战役号取自 EXE 关卡表标题；城镇地名按城镇传闻文字推定（如 8 号城镇传闻"这里是郓城县"），5、9、12、13 号城镇传闻没写地名，按剧情路线推测。原版只有「第N章 戰役N」。
- **主角**：开局输入姓名和绰号，默认"武龍""關西之虎"。
- **开局道具【新】**：第一关 N01 里武龍、王進各带 2 个狗皮膏藥（原版职业默认只有 1 个；负责人 2026-11-12），见 `START_ITEMS`（`src/rules/battle.ts`）。

### 1.4 队伍与出场

- **部署**：按每关 ACT 中的单位和坐标部署，没有自由选人。
- **断后选人**：N-add15 中"請選擇留下的人"，由主角加一名玩家选的队员留下作战。选人界面和战后归队方式【待核】。
- **延迟出场**：ACT 中标为"不在场"的单位开局隐藏，剧本点名时登场。例如武龍在 N01 第 3 回合登场；敌方增援也用同一机制。
- **埋伏**：AI 模式 6 的单位开局不在地图上，有敌人进入警戒半径时现身并行动（EXE 0x407ac0）。
- **号令**：N-add03 王進与莊客埋伏，每个我方阶段开始时问"好！大家上！/不行...还不够近，再等等...."，选前者全员现身（原版在友军阶段由模式 9 的莊客弹出，EXE 0x407af3）【新：时机】。
- **等级**：好汉在 ACT 里多写 Lv1，表示沿用当前等级；新加入的人写明确等级（林沖 10、魯智深 7、楊志 18…）。

## 2. 战场

### 2.1 地图

- **格子**：菱形等距格，每格画面 90×46。地图有 18×18、36×36、54×54 三种尺寸，另有一张 36×54。
- **坐标**：格子 (x, y) 的屏幕中心 = ((x − y) × 45, (x + y) × 23)。
- **图层**：每格 1 层地表，加 0–4 层地上物。
- **绘制顺序**：先画地表，再按 x + y 从远到近画地上物和单位。单位被遮挡时半透明显示【新】。

### 2.2 通行

- **图块通行**：按原版 EXE 0x40bc30 的规则（binary-formats §5.1）：地表 0 号或 Ground.att = 0xFF 阻挡；第一层地上物与地表同高时看 Upper.att，高出地表（树冠等）不阻挡，低于地表阻挡。需要时再用人工修正表 `content/passability.json` 补正。
- **单位阻挡**：有单位的格子不能穿越，友方也一样；敌人会绕开挡路的单位。
- **不做的规则**：没有地形效果，也没有区域控制（ZOC）。

### 2.3 朝向

- 单位有 4 个朝向。移动或攻击后，单位面向最后的方向；受击时转向攻击者。
- 朝向会影响命中（§4.1）。

### 2.4 回合

- 先是我方全体行动，然后友军，最后敌方【新：原版顺序待核】。
- 每回合开始时依次结算：
  1. 装备带来的每回合回复；
  2. 中毒扣血；
  3. 状态和增益的回合数减 1。

### 2.5 单位指令

| 指令 | 规则 |
|---|---|
| 移動 | 见下方移动规则 |
| 普通攻擊 | 攻击后用完剩余移动力，本回合行动结束。目标必须与攻方同行或同列，距离在射程内（原版只沿 4 个方向直线找目标，EXE 0x40d850） |
| 特殊攻擊 | 使用技能，消耗气力 |
| 防御 | 结束行动并进入防御状态，直到下次行动。效果：受到的命中率 ×0.7、伤害 ×0.7，闪避相邻攻击时可能反击（§4.2） |
| 使用 | 使用道具，不算行动、不消耗移动力、不限次数（原版命令执行 0x409690 第 7 项 → 0x408dc0，不碰行动结束标志）。对象 = 自己和上下左右相邻格的非敌方单位（选择指令 0x409618 调 0x40d5d0(位置, 0, 1) 标出距离 0–1 的 4 个方向；执行时 0x409798 只拒绝敌方）。能用的是类型 15–22；财宝（23）不能用，古武術祕笈（24）暂未做 |
| 裝備 | 战斗中换装备，不算行动（原版命令 8 在执行表 0x4097e8 中为空，菜单里直接完成）。物品栏里的装备换进对应装备栏，装备栏里的卸到第一个空的物品栏；规则与整备相同 |
| 給予 | 把道具交给上下左右相邻的我方人物（选择 0x4095ec 调 0x40d5d0(位置, 1, 1)；执行 0x409752 要求对方 unit+0x3b = 0），放进对方物品栏的第一个空位（原版 3–6 格，重制版 10 格），装备也一样（0x409460），满了就不给；打铁次数跟着走。不算行动 |
| 丟棄 | 丢弃道具，不算行动 |
| 休息 | 结束行动，体力和气力各恢复上限的 1/5【新：负责人 2026-11-12 决定，原版恢复得更少】 |
| 人物資料 | 查看属性 |

**移动规则**：

- **绿色范围**：在剩余移动力内移动，可以分多段走，走完仍能行动。
- **黄色范围**：强行军，可以走得更远，但到达后本回合结束。在剩余移动力之外再加「移动力 ÷ 2，向上取整」格【新】。原版固定多 1 格（负责人回忆，2026-11-11），负责人决定沿用新做法。
- **状态字段**：每个单位记录 `movementRemaining`、`forcedMarch`、`attackUsed`、`actionEnded`。

**便利功能**【新】：撤销最近一次移动、全体待机、敌方回合快进；我方能行动的人都行动完毕后自动结束回合（阵亡、未登场、昏迷的人不算；最后一个动作播完、稍停 0.4 秒再结束，对白显示中不触发）。

**道具菜单**【新：界面不照搬原版】：行动菜单的"道具"列出 3 格装备（空的也列）和物品栏里的东西，每格写着效果。点一格显示名称、效果和原版说明，再选使用 / 装备或卸下 / 给予 / 丢弃；使用和给予时地图上标出可选的人，也可以直接点按钮。丢弃要再确认一次。已经行动过的我方人物也能打开道具栏查看。

## 3. 单位属性

| 属性 | 原版名称 | 作用 | 每级成长【新】 |
|---|---|---|---|
| 生命 | 體力 | 归零即"戰敗" | 2 + 初始值 × 2.5% |
| 气力 | 氣力 | 技能消耗 | 2 + 初始值 × 2% |
| 攻击 | 攻擊力 | 伤害 | 1.5 + 初始值 × 3% |
| 防御 | 防禦力 | 减伤 | 2 + 初始值 × 8% |
| 命中 | 命中率 | 命中 | 2 + 初始值 × 4% |
| 敏捷 | 敏捷度 | 闪避 | 1 + 初始值 × 6% |
| 必杀 | 必殺率 | 暴击 | 0.4 + 初始值 × 3.5% |
| 移动 | 移動力 | 移动距离（3–7，加装备） | 不成长 |
| 等级 | — | 成长 | 我方 30；敌方不限（最高 42） |

**属性计算**【新】（负责人 2026-11-12 定，代码 `src/rules/growth.ts`），每次升级、换装、状态变化后重算：

```
属性 = floor(初始值 + 等级 × (固定点数 + 初始值 × 百分比))     不封顶
     + 3 件装备的加成（攻防取装备当前值，含打铁提升）
     + 永久加成（兵书）+ 增益道具
中毒时攻击、防御减半
```

- **原版**（EXE 0x408540）：属性 = 基础值 × (成长%/100)^等级，攻防等封顶 255、生命气力封顶 510；成长 102–110% 每人每项不同。防御、敏捷几乎都是 110%，攻击只有 104–105%，后期大家都顶到 255，好汉之间没有区别，也是后期打不动的根源之一（§4.2）。
- **重制版**：好汉和所有敌人用同一条成长规则。每级大约一半是固定点数、一半看初始值：大家成长相近，初始值高的那项长得更快，保留各自特色。固定点数和百分比按"好汉平均值在 10 级时与原版接近"来定，前期节奏不变；之后每级加的点数不变，不再越涨越快。初始值来自职业表（[data-tables.md](reference/data-tables.md) 的"基础值"），原版的成长百分比不再使用。
- **个别调整**：王進初始攻击 70 → 80（负责人 2026-11-12：新成长下前期显弱，前期打兵伤害约 +15%）。调整写在 `growth.ts` 的 `CLASS_OVERRIDES`。
- **移动力调整**：武龍基础移动力 5 → 6（负责人 2026-11-12）。写在 `data.ts` 的 `CLASS_MOVE_BONUS`，读职业表时就加上，所以每一关、城镇面板和强行军范围都按 6 算；[data-tables.md](reference/data-tables.md) 仍列原版值 5。
- 例：武龍攻击初始 65，每级 +3.45：1 级 68，10 级 99，30 级 168。28 级时好汉的攻防大约 160–230，生命 200–300。

### 3.1 敌兵模板【新】

负责人 2026-11-12 定：敌方普通单位用统一模板，同档同等级的兵属性完全一样，之后再按兵种加小偏移。

| 档次 | 职业 | 初始值（生命 / 气力 / 攻 / 防 / 命中 / 敏捷 / 必杀） | 装备固定加成 |
|---|---|---|---|
| 杂兵 | 莊客、漁人、囉嘍、士兵、弓箭手、官吏、家人、徒弟（职业 19–23、32–34、36、37、40、41、44、45、67） | 55 / 45 / 50 / 20 / 55 / 22 / 0 | 生命 +3、气力 +5、攻 +15、防 +13、敏捷 +5 |
| 小头目 | 都頭、教頭、縣尉、騎兵、頭領、刺客（38、39、42、43、65、66） | 95 / 80 / 66 / 28 / 70 / 30 / 12 | 生命 +3、气力 +8、攻 +6、防 +16、敏捷 +8 |

## 4. 战斗规则

行动前在界面上显示命中率和预计伤害。

### 4.1 命中

```
命中率 = 攻方命中 / (攻方命中 + 守方敏捷 / 2) × 100 + 技能命中修正【新】
       × 朝向系数：打背后 1.5，打侧面 1.3，打正面 1.0
       × 0.7（守方在防御状态）
最高 100%，敌我同一公式，没有保底【新】
```

- "背后"指攻守双方朝向相同，"正面"指朝向相反，其余为侧面。
- **原版**（EXE 0x406c60）：命中率 = 命中 − 敏捷/2 + 修正，我方保底 80%（重制版曾改为 90%）、其它保底 30%。等级越高差值越大，所以改成比例；负责人 2026-11-12 要求敌我同一公式，命中高低改由敌兵数值体现（§3.1）。
- 按各关推荐配置，正面普通攻击：我方打杂兵约 80–89%，杂兵打我方约 70–78%，前后期都稳定。魯智深命中低、普通攻击还带 −10，约 67–69%。
- 未命中时显示 "MISS"。

### 4.2 伤害

```
必杀率 = (攻方必杀 + 技能必杀修正) / 2
A = 攻 + 技能威力
普通：伤害 = A² / (A + 2 × 防)【新】
必杀：伤害 = (2A)² / (2A + 2 × 防)【新】（把 A 翻倍再代入）
远程攻击（技能类型 10）：× 距离系数【新】
守方在防御状态：× 0.7
最后 × 0.9–1.1【新】，取整，至少 0
```

- 普通攻击的技能威力大多为 0；少数带威力（白勝、魯智深 +20，劉唐、陳達、林沖 +15）。
- **多段攻击**【新】（负责人 2026-11-12）：先按上式算出普通和必杀两种总伤害（含防御 × 0.7 和浮动），按技能各段比例拆开（例：九死一生 30% / 50% / 20%），**每段单独判定命中和必杀**：落空的段为 0 并显示 MISS，必杀的段取必杀伤害的那一份。至少一段命中就算命中（中毒、昏迷判定一次）；全部落空才算闪避（可能触发反击）。单段攻击与原来一样。原版只判定一次，多段只是分段显示。
- **比例公式**【新】（负责人 2026-11-12 选）：原版是 普通 = A − 防、必杀 = 2A − 防，≤ 0 时改为 10–59 的随机值（EXE 0x406c60）。几乎所有职业防御每级 ×1.10、攻击只有 ×1.04–1.05，又都封顶 255，约 20 级后防御反超攻击：第 11 章起我方普通攻击要 10–20 下才打倒一个小兵，敌方打我方从第 5 章起就基本只剩这个随机数，只有必杀率高的人（楊志等，后期必杀率 60–100%）打得动。比例公式下攻防在任何阶段都起作用。防御权重取 2 是为了前期节奏不变（负责人要求）：按各关推荐配置算，第 1–5 章双方普通伤害与原版相差约 ±10%，几下打倒对方基本一样，必杀约为原版的九成；后期我方约 2.5–3 下打倒小兵（原版 10–20 下），小兵约 6–10 下打倒我方（与原版后期相近），必杀约 220–260（与原版相近）。
- **远程按距离打折**【新】（负责人 2026-11-12）：类型 10 的远程攻击（弓箭手的普通攻击，射程 1–8；白勝「監守自盜」；富安「笑裏藏刀」）伤害最多为上式的 50%，最少为 10%：距离 1 为 50%，到最远射程线性降到 10%（系数 = 0.5 − 0.4 × (距离 − 1) / (最远射程 − 1)）。弓箭手 1–8 格依次约 50%、44%、39%、33%、27%、21%、16%、10%。生命等属性不变。原版远程与近战同一公式；本来弓箭手离 8 格射一箭和士兵贴身砍一刀伤害相同，又不会被反击。
- 例：1 级武龍（攻 68）打防 20 的士兵，约 43 点（68² / (68 + 40)；原版 48）。
- 战报照原版字样："N 點傷害。""未造成敵方傷害。"。范围技能合计显示为"造成敵方總共 N 點傷害"。

### 4.3 反击

- 守方处于防御状态时，闪避了正交相邻的攻击，有 50% 几率立即用普通攻击反击。
- 反击必定命中，战报为"施展反擊技，"。
- 除此之外没有其它反击。

### 4.4 中毒与昏迷

- **中毒率** = 技能中毒率 + 攻方装备的中毒率；**昏迷率**同理。
- 攻击命中后分别判定。判定成功的状态持续 2–4 回合；守方在抗毒或抗昏期间不会中招。

| 状态 | 消息 | 效果 | 解除 |
|---|---|---|---|
| 中毒 | "中毒了！""毒發，生命力損失 N 點。" | 攻击、防御减半；每回合开始扣最大生命的 1/20 | 到期、解毒草藥、天山雪蓮 |
| 昏迷 | "昏迷了！" | 不能行动 | 到期、解昏迷草藥、天山雪蓮 |
| 增益 | — | 按道具数据，如人參藥酒"3 回合內攻擊力提升5點"；同一项再用一次以新的为准，不叠加【新】；移动力增益当回合就加到剩余移动力上 | 到期 |
| 抗毒 / 抗昏 | — | 期间不会中毒 / 昏迷（清涼丸、提神丸） | 到期 |

### 4.5 回复技与集气技

- **回复技**：回复量 = 目标最大生命 / 技能威力字段。例：字段为 3，回复 1/3 的最大生命。
- **集气技**：回复量 = 目标最大气力 / 技能威力字段。
- 两种技能都不会超过上限。

| 类型 | 形状 | 原版函数 |
|---|---|---|
| 0 氣功、5 普通、6/10 遠程 | 从施放点沿施放方向一条线，长 size 格 | 0x40cf90 |

- 使用技能后与普通攻击一样，结束这个单位的行动。

### 6.4 特效

`Effect.lib` 有 60 组特效（0 起编号）。播哪几组、在哪、何时播，全部按 EXE 静态分析还原（2026-11-12，证据见 binary-formats §4.1；实现在 `src/game/effects.ts`）：

- **选组**：技能子项 +6、+24、+26 各是一段特效号（组号 + 1，0 = 无）。但有类型例外：集气技（类型 8）一律播第 7 组；回复技（类型 9、11）一律播第 17 组，+6 只表示"有没有特效"；迴旋技（类型 2）不播特效；遠程（类型 10）按方向选组，+6 − 1 再加方向 0–3（第 52–55 组弓箭、56–59 组飞刀）。
  - 例：朱武回復計、吳用如魚得水的 +6 是 19，与史進天龍出雲相同，但原版播的是第 17 组（星光），不是第 18 组（光环）。
- **接力**：每格先播 +6 那组；播到这组的触发帧（EXE 表 0x4435e8）时，有 +24 就在同一格接着播；再到触发帧时，+26 有值且这一格有可作用的单位才播（命中特效）；最后一段到触发帧时才结算这一格的伤害 / 回复。
- **范围**：特效铺满整个作用范围，从施放点每个特效帧向外扩一圈（线形按距离，扇形按行，菱形按曼哈顿距离【菱形按圈为推测】）；遠程从施放者脚下逐格飞向目标。
- **时机**：每个命中帧放一轮（多段技能放多轮）；集气技和类型 9 的回复技在出手动画结束后才放。
- 帧间隔：原版每个特效对象 75 ms（构造函数 0x4036ad），重制版和人物出手一样加快到 60 ms【新】。

## 7. 装备、道具、城镇与经济

### 7.1 装备栏

- 每人 13 栏：武器、衣服、头饰各 1 栏，物品 10 栏【新：原版物品只有 4 栏，负责人 2026-11-12 要求加到 10 栏左右】。旧存档的 7 栏读入时补齐。只有前 3 栏的装备算加成，放在物品栏的装备不算（EXE 0x408803 只循环 3 格）。
- 头饰栏也放饰品、玉、护符、兵法（道具类型都是 14）。
- 道具不堆叠。
- 每个职业只能装备一类武器：手套/拳、棍、雙刀、大刀、槍、禪杖/鏟、刀、劍、雙劍、叉、槳、弓。重制版按职业表 +25 的武器类型判断，也允许该职业默认武器的类型（阮小五武器类型是刀，默认却带朴刀）【待核】。

### 7.2 装备属性

装备的属性全部来自道具表：

- 攻防、命中、敏捷、必杀、移动、射程加成；
- **移动只加不减**【新：负责人 2026-11-12 决定】：原版后期不少装备扣移动力（道具 +104 为负），重制版一律当 0；加移动的仍按原版数值（`equipMoveBonus`）；
- 生命和气力上限加成；
- 每回合回复的生命和气力；
- 附带的中毒率和昏迷率。

### 7.3 打铁

- **规则**：每件装备有每次提升的攻击量、防御量和可提升次数。例：青絲手套攻击 9，每次 +2，可以提升 4 次。
- **费用**：每次提升收买价的一半，攻击和防御中还有剩余次数的项会一起提升。
- **地点**：只有道具表里列出的城镇的打铁铺可以提升这件装备。
- **提示**："攻擊力提升了 N 點""防御力提升了 N 點"；钱不够时"金錢不夠，無法提升！"。

### 7.4 消耗品

效果全部来自道具表：

- 回复体力或气力（−1 表示回满）；
- 解毒、解昏；
- 抗毒、抗昏 N 回合；
- 限时增益：攻、防、命、敏、必、移动加值 N 回合；
- 攻击附带中毒或昏迷（金蠶蠱毒粉、悲酥涼風粉）：按说明做成 N 回合内攻击带毒 / 致昏 %【新】。原版 0x4091b1 把 +130 交给 0x404a70，让使用对象自己中毒，+134/+136 不读，看起来是原版的错（推测）；
- 古武術祕笈（+138，学会隐藏技）：重制版暂未实现，可以给予、丢弃。

道具说明与数据不一致时以数据为准（萬靈藥的说明是回复 200，数据是 510）。

### 7.5 城镇

菜单式，每个城镇按其城镇号决定货品和打铁范围。

- **在哪里**：关卡 `.pab` 文件头 +9 是过关后进入的城镇号。全游戏 13 个城镇：N-add01 → 1、Act3-4 → 2、Act5-1 → 3、N-add07 → 4、N07 → 5、N-add09a → 6、N-add09b → 12、N09 → 7、Act11-2 → 8、Act13-1 → 9、Act14-1 → 10、N-add16 → 11、Act7-1 → 13。
- **货品**：道具 +1 大类 = 店序号 + 1，且道具 +146 的城镇号表含本城（EXE 0x414a40）。城镇号表按游戏进度排列，越往后能买的东西越多。
- **卖东西**：只有當鋪能"典當"，按道具卖价（+144）收钱；其它店只能买。

| 店铺 | 菜单 | 卖什么 |
|---|---|---|
| 酒店 | 交談、買、物品 | 酒、包子（大类 1）。交谈依次说出本城的传闻（EXE 传闻表，城镇 5、9 没有） |
| 武器店 | 買、物品 | 武器、衣服、头饰（大类 2） |
| 打鐵鋪 | 打鐵、物品 | 见 §7.3 |
| 藥鋪 | 買、物品 | 药（大类 4） |
| 當鋪 | 典當、買、物品 | 饰品、玉（大类 5） |

"物品"即整备（装备、卸下、给予、丢弃）。

**已实现**：

- 过关后，文件头有城镇号的关进城镇：战役在结算界面点"进入城镇"，剧情关直接进城。城镇里每次买卖都会存档，刷新页面回到城镇。离开城镇 2、5 时问分路（见 §1.2），其它城镇离开后直接进下一关。
- 没有城镇的关：结算界面多一个"整备"按钮，可以先换装备、整理道具再进下一关。
- 买东西时先选买给谁；能装上且装备栏空着就直接装上，否则放进物品栏。不合本职业的武器标"不合用"。
- 打铁次数跟着道具走（给予别人也保留），存档里记在 `forge`。
- 整备和商店只列上一关出场的我方人物（中途退场或一直没登场的不列）。
- 城镇 6 第一次交谈的柴進对白、城镇 12 的告别语特例、"系統選項"还没做。

### 7.6 金钱

- 击倒敌人得到黄金，数额 = 1 至该职业金钱上限之间的随机数。例：士兵 50、都頭 200、高俅 500；好汉为 0。
- 提示"擊退了敵人，得到黃金 N 兩！"。
- 地图上的宝物（ACT 中阵营为"物件"的单位）：只有我方能拾，物品号 > 200 的不能拾（EXE 0x4054e0、0x409460）。原版要踩上宝箱那一格（移动路上经过也算）才拾起。
- 重制版【新：负责人 2026-11-12】：我方人物走到宝箱上或上下左右相邻的格子（移动路上经过也算）就自动打开，东西放进物品栏的第一个空位。物品栏满了打不开，宝箱留着，提示"某某的道具已滿，打不開寶箱。"（原版不提示）。
- 宝物在地图上一律画成宝箱（`Grid.grp` 第 4 帧），看不出里面是什么（EXE 0x40c24f 调 0x4010e0 把帧号设为 4，0x4010d0 从 `data\grid` 取帧）。没有开箱动作，拾起时播放 m07。
- ACT 里标了"开局隐藏"（w7 低字节非 0）的宝物不画在地图上，但照样能拾：原版只清掉显示标志 0x2，宝物仍挂在格子上（0x4033e8 → 0x40c240），绘制与小地图都检查这个标志（0x410960、0x4011a0）。这些宝物编组号都是 0，剧本不会让它们出现，是给玩家碰运气找的暗藏宝物（共 21 个，如 N02 (25,5)、N03 (32,21)、N12 三个）。

## 8. 敌方与友军 AI

每个单位的 AI 模式写在关卡的 ACT 中，直接按模式实现：

| 模式 | 行为（EXE 0x407930 跳转表） |
|---|---|
| 0 | 默认行为：生命低于 1/5 时先用回复道具；打得到就打，否则朝单位表里第一个敌对单位前进（0x408080、0x40d930）。敌方大多是这个模式 |
| 1、10 | 追击 w8 指定的角色：打得到就打，否则朝它移动 |
| 2、6 | 迎击：警戒半径内有敌人才出动（打得到就打，否则靠近），否则原地待命。警戒半径（曼哈顿距离，0x407fa0 → 0x40d680）= 移动力 + 技能射程上限 + 装备射程 + 技能范围大小；原版用 AI 先选好的技能，重制版取气力够用的攻击技能里最远的。模式 6 现身（0x408450）就是清掉埋伏标志、模式改为 0、登场 |
| 3 | 固守：只攻击"移动 + 射程"内的敌人，打不到就不动 |
| 4 | 先走到 (w9, w10)，到达后转为模式 2 |
| 5 | 跟随 w8 指定的角色，不攻击（N01 王母跟随王進，玩家不能操作她）。体力不满时移动后自动休息；体力满且普通移动到不了目标旁边时用强行军（多走「移动力 ÷ 2，向上取整」格，走完本回合结束）【新：负责人 2026-11-12】 |
| 7 | 不在场，被事件放出后按默认行为行动 |
| 8 | 原地不动 |
| 9 | 原版会生成一个对象，数据中未使用；按默认行为处理 |

- **选目标**【新】：原版只按方向和距离逐格找能打的位置，不挑目标。重制版先打主要目标（单位表里第一个敌对单位，N01 是王進），其次能击倒的，再次少走路、期望伤害高。
- **选技能**【新】：在普通攻击和气力够用的攻击技之间选，顺序为：打到主要目标 → 击倒人数多 → 少走路 → 期望伤害高（技能的期望伤害先减去气力消耗的一半，免得为一点伤害耗光气力）。
- 体力低于一半且有回复技时先回复；打不到人且气力不到一半时，走完后用集气技【新】。
- **埋伏台词**：EXE 中有"不行...還不夠近，再等等....""好！大家上！"，说明有"等玩家靠近再出击"的演出。由事件脚本实现【待核：对应哪种模式】。

## 9. 剧情与事件

### 9.1 文本

- 853 句对白，以及全部旁白、胜负条件和结局文字，都按原文使用。
- 文本中的 `%N`、`%X` 替换为主角名，`%M` 替换为主角绰号（EXE 0x4106b4）。
- 头像来自 `Head.lib`（79 张），第 i 张对应 HUM 第 i 个职业（见 binary-formats）。对白框和人物面板都显示头像。

### 9.2 事件脚本

每关的事件直接执行原版 PAS 区块（结构见 binary-formats §8，实现在 `src/rules/battle.ts`）；解不开的部分以后再手写补充到 `content/stages/<关卡>.events.json`。

**已实现**：回合触发、死亡触发（角色号 255 = 敌方全灭）、区域触发、号令触发；指令 12 选人（隐藏的随之登场）、13 说话、14/15 坐标、16/17 动作（改 AI 模式、设目标、退场、移动）、29 过关旁白、30 结局文字（执行后判负）、31–33 条件文字、35 回合限制，含义见 binary-formats §8。含指令 29 的区块执行完即过关，含 30 的判负。开场没有我方人物的剧情关（如 Act3-3）不判全军覆没。对白用 `.pas` 的简体文字显示，其它原版字符串（人名、道具名、战报）按 `.pab`/`.pas` 逐字对齐得到的繁简对照转换。

**触发器**：

- 第 N 回合；
- 某单位死亡；
- 某单位进入区域；
- 对话结束。

**动作**：

- 对白、旁白；
- 放出单位 / 增援（"敵軍增援了！"）；
- 移动；
- 改变 AI 模式；
- 加入队伍、给道具；
- 播放音效；
- 中途改变胜负条件（如 N-add09a 从"打敗所有敵人"改为"打敗縣尉"）；
- 胜利、失败并播放对应结局。

**选择**：`chooseRoute`（路线分支）、`chooseUnits`（断后选人）。

示例：

```jsonc
// content/stages/N01.events.json（示意）
{
  "objective": {
    "turnLimit": 50,
    "win":  [{ "reach": { "unit": "王母", "area": "escape" } }],
    "lose": [{ "dies": "王進", "ending": "lose_wangjin" }, { "dies": "王母", "ending": "lose_mother" },
             { "dies": "$hero", "ending": "lose_hero" }, { "turnLimit": true, "ending": "lose_timeout" }]
  },
  "events": [
    { "on": "start", "do": [{ "say": "王進", "line": "pab:N01#0" }] },
    { "on": { "turn": 3 }, "do": [{ "activate": "hero" }] }
  ]
}
```

N01 的原版事件（已全部由 PAS 直接驱动）：开战时王進、王母走到 (6,6)/(6,5) 并对白；第 3 回合武龍登场；王母、王進、主角战败各有一段结局；第 50 回合结束判负；王母进入 (23–25, 52–53) 胜利。

对白用 `pab:关卡#序号` 引用原文，不把文本复制进事件文件。

## 12. 技术架构

### 12.1 模块

```
src/
  formats/   原版格式解析（已有），浏览器与 Node 共用
  data/      整理成游戏数据：Character、ClassDef、Item、Skill、StageDef、StageGraph
  rules/     纯 TypeScript 规则引擎：棋盘、寻路、行动状态机、战斗、AI、事件；不依赖 Phaser
  game/      Phaser 4 场景：Boot、Setup、Title、Naming、Story、Battle、Town、Settings
  content/   手写内容：事件脚本、stageGraph、通行修正、头像对照
tools/       Node 工具：gen-design-docs（生成 reference/）、render-maps（地图预览）
```

### 12.2 关键设计

- **原版文件来源**：
  - 网页版从 `raw.githubusercontent.com/loolos/ShuihuLSHH/main/gamedata/shuihu/` 下载（`loadFromRepo`）。小文件（剧本、地图、数据表、头像，约 3 MB）启动时整份下载；`Man.lib`、`Effect.lib`、`Ground.grp`、`Upper.grp` 只先取文件头和索引，进关前（`preloadStage`）用 HTTP Range 只取地图用到的图块，以及本关出场职业的走路、受击、防御动作和普通攻击（含特效）；各单位已学会的技能动画和特效开打后在后台下载（`prefetchSkills`），出招时还没下完就等它下完（`ensureSkill`，升级后新学的技能也在这时下载）。`Man.lib` 有 6480 帧、`Effect.lib` 有 76 帧与前面的帧字节完全相同（共约 11.5 MB），只下载第一份再复制过去（帧号表 `src/data/frame-alias.json`，由 `npm run gen:manifest` 生成）。`Panel.lib` 暂不使用，不下载。各关下载量用 `node --experimental-transform-types tools/measure-assets.ts` 统计：单关进关前最多从约 27 MB 降到约 12 MB，全部关卡玩完共下载约 42 MB（原来约 56 MB）。【新】
  - 下载过的文件和分段都存进 IndexedDB，再次打开或回到玩过的关卡不再下载。
  - 下载失败时退回到选择原版目录：File System Access API，不支持的浏览器用 `<input webkitdirectory>` 兜底。
  - 对照 `src/data/manifest.json`（267 个文件，65 MB）检查文件是否齐全、SHA256 是否一致；不一致时提示，但允许继续。
  - 原始文件字节缓存到 IndexedDB，下次启动不用再选目录；图像按需解码，解码结果只留在内存里。
  - 开发模式直接读取仓库里的 `gamedata/shuihu`。
  - 如果首次解码变慢，再把解码移到 Web Worker。
- **规则与表现分离**：`rules/` 输出事件流，`game/` 只负责播放。这样快进、单元测试和数值模拟都不依赖画面。
- **数据驱动**：
  - 所有数值读自原版数据（职业表、道具表、ACT）。
  - 【新】规则的参数集中写在 `content/balance.json`。
  - 人工修正放在 `content/overrides/`，不改解析结果。
- **随机数**：可设种子的随机数生成器；读档后重新随机。
- **存档**：JSON 存在 IndexedDB，可以导出和导入。
- **调试工具**：离线提取工具继续保留，用于生成预览，产物写到 `extracted/`。
